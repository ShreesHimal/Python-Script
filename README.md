# Python Script

This repository is a collection of automated Python scripts. Each project is organized in its own folder with its script and project-specific documentation.

## Automated scripts

- [`automated ffuf script/`](automated%20ffuf%20script/) — Automates ffuf scans for one target or a list of targets. The folder contains the script, usage documentation, and project-specific ignore rules.

Only run scanning tools against systems you own or are authorized to assess.
